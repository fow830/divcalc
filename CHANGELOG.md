# Changelog

Все значимые изменения в проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2025-01-16

### Добавлено
- Калькулятор стоимости диванов с интерактивным интерфейсом
- Поддержка 5 моделей диванов (Chesterfield, Savoy, Balmoral, Barclay, Viscount)
- Расчет стоимости с учетом:
  - Ширины локтей и спинки
  - Цены обивки (в м² или метрах погонных)
  - Коэффициентов сложности и наценки
- API endpoint для получения данных моделей
- Адаптивный дизайн с использованием shadcn/ui
- Интеграция с GitHub (репозиторий fow830/divcalc)
- Скрипты для автоматизации деплоя

### Технические детали
- Next.js 14 с App Router
- TypeScript
- Tailwind CSS
- shadcn/ui компоненты
- Данные моделей встроены в код (без зависимости от Excel)
