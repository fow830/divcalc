# Калькулятор стоимости диванов

Веб-приложение для расчета стоимости производства диванов на основе параметров из Excel файла.

## Технологии

- **Next.js 14** - React фреймворк с App Router
- **TypeScript** - типизированный JavaScript
- **Tailwind CSS** - утилитарный CSS фреймворк
- **shadcn/ui** - компоненты UI
- Данные хранятся в коде (извлечены из Excel)

## Функциональность

- ✅ Данные моделей и параметров хранятся в коде
- ✅ 5 моделей диванов с индивидуальными параметрами
- ✅ Расчет стоимости в реальном времени без перезагрузки страницы
- ✅ Учет всех параметров: ширина локтей, ширина спинки, цена обивки, тип измерения
- ✅ Применение коэффициентов сложности и наценки
- ✅ Минималистичный светлый дизайн

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev сервер:
```bash
npm run dev
```

4. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## Структура данных

### Фиксированные данные (одинаковые для всех моделей):
- Цена производства локтей за 1 см
- Цена производства спинки за 1 см
- Расход обивки локтей за 1 см (в м² и мп)
- Расход обивки спинки за 1 см (в м² и мп)

### Параметры моделей:
- **Chesterfield**: ширина локтей 70 см, коэффициент сложности 1.0, наценка 2.5
- **Savoy**: ширина локтей 20 см, коэффициент сложности 0.95, наценка 2.5
- **Balmoral**: ширина локтей 50 см, коэффициент сложности 0.9, наценка 2.5
- **Barclay**: ширина локтей 30 см, коэффициент сложности 0.85, наценка 2.5
- **Viscount**: ширина локтей 20 см, коэффициент сложности 0.8, наценка 2.5

## Формулы расчета

### Производство локтей:
```
Ширина локтей × Цена производства × Коэффициент сложности × Коэффициент наценки
```

### Производство спинки:
```
Ширина спинки × Цена производства × Коэффициент сложности × Коэффициент наценки
```

### Обивка локтей:
```
Ширина локтей × Расход обивки (м² или мп) × Цена обивки
```

### Обивка спинки:
```
Ширина спинки × Расход обивки (м² или мп) × Цена обивки
```

## Деплой на сервер

### Важные требования

✅ Все данные уже включены в код проекта, дополнительные файлы не требуются.

### Вариант 1: Деплой на Vercel (рекомендуется)

1. Установите Vercel CLI:
```bash
npm i -g vercel
```

2. Запустите деплой:
```bash
vercel
```

Или подключите репозиторий на GitHub к Vercel через веб-интерфейс.

**Важно**: Все данные уже в коде, дополнительных файлов не требуется.

### Вариант 2: Деплой с Docker

1. Соберите Docker образ:
```bash
docker build -t sofa-calculator .
```

2. Запустите контейнер:
```bash
docker run -p 3000:3000 sofa-calculator
```

### Вариант 3: Деплой на обычный сервер

1. Установите зависимости на сервере:
```bash
npm ci --production
```

2. Соберите приложение:
```bash
npm run build
```

3. Запустите приложение:
```bash
npm start
```

Или используйте PM2 для управления процессом:
```bash
npm install -g pm2
pm2 start npm --name "sofa-calculator" -- start
pm2 save
pm2 startup
```

### Переменные окружения

Создайте файл `.env.local` (не коммитьте его в репозиторий):
```
PORT=3000
NODE_ENV=production
```

3. ✅ Проверьте работу локально: `npm run dev`

### Troubleshooting

**Проблема**: Ошибки при сборке
- **Решение**: Проверьте, что все зависимости установлены: `npm install`

**Проблема**: Приложение не запускается
- **Решение**: Проверьте переменные окружения и порт

**Проблема**: Данные не загружаются
- **Решение**: Проверьте, что файл `lib/data.ts` существует и содержит данные
