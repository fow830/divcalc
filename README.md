# Калькулятор стоимости диванов

Веб-приложение для расчета стоимости производства диванов на основе параметров из Excel файла.

## Технологии

- **Next.js 16** - React фреймворк с App Router
- **TypeScript** - типизированный JavaScript
- **Tailwind CSS** - утилитарный CSS фреймворк
- **shadcn/ui** - компоненты UI
- Данные хранятся в коде (извлечены из Excel)

## Функциональность

- ✅ Данные моделей и параметров хранятся в коде
- ✅ 5 моделей диванов с индивидуальными параметрами
- ✅ Расчет стоимости в реальном времени без перезагрузки страницы
- ✅ Учет всех параметров: ширина локтей, ширина спинки, цена обивки, тип измерения
- ✅ Применение коэффициентов сложности и наценки
- ✅ Минималистичный светлый дизайн

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev сервер:
```bash
npm run dev
```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## Структура данных

### Фиксированные данные (одинаковые для всех моделей):
- Цена производства локтей за 1 см
- Цена производства спинки за 1 см
- Расход обивки локтей за 1 см (в м² и мп)
- Расход обивки спинки за 1 см (в м² и мп)

### Параметры моделей:
- **Chesterfield**: ширина локтей 70 см, коэффициент сложности 1.0, наценка 2.5
- **Savoy**: ширина локтей 20 см, коэффициент сложности 0.95, наценка 2.5
- **Balmoral**: ширина локтей 50 см, коэффициент сложности 0.9, наценка 2.5
- **Barclay**: ширина локтей 30 см, коэффициент сложности 0.85, наценка 2.5
- **Viscount**: ширина локтей 20 см, коэффициент сложности 0.8, наценка 2.5

## Формулы расчета

### Производство локтей:
```
Ширина локтей × Цена производства × Коэффициент сложности × Коэффициент наценки
```

### Производство спинки:
```
Ширина спинки × Цена производства × Коэффициент сложности × Коэффициент наценки
```

### Обивка локтей:
```
Ширина локтей × Расход обивки (м² или мп) × Цена обивки
```

### Обивка спинки:
```
Ширина спинки × Расход обивки (м² или мп) × Цена обивки
```
