# Настройка GitHub репозитория

## 📋 Текущий статус

- ✅ Git репозиторий инициализирован локально
- ✅ Создан начальный коммит
- ✅ Создана ветка `stage`
- ⏳ Репозиторий на GitHub нужно создать

## 🚀 Создание репозитория на GitHub

### Вариант 1: Через веб-интерфейс (рекомендуется)

1. Откройте: https://github.com/new
2. Заполните:
   - **Repository name**: `divcalc`
   - **Description**: `Калькулятор стоимости диванов`
   - **Visibility**: Public ✅
   - **НЕ** добавляйте README, .gitignore или лицензию (у нас уже есть)
3. Нажмите "Create repository"

### Вариант 2: Через GitHub CLI (если установлен)

```bash
gh repo create divcalc --public --source=. --remote=origin --push
```

### Вариант 3: Автоматический скрипт

```bash
./scripts/setup-github.sh
```

## 📤 Пуш кода в ветку stage

После создания репозитория на GitHub:

```bash
git push -u origin stage
```

## ✅ Проверка

После успешного пуша репозиторий будет доступен по адресу:
**https://github.com/fow830/divcalc**

Ветка `stage` будет содержать весь код проекта.

## 🔄 Структура веток

- **main** - основная ветка (пока пустая)
- **stage** - ветка для стейджинга (содержит текущий код)

## 📝 Следующие шаги

После создания репозитория и пуша:

1. Можно настроить GitHub Actions для автоматического деплоя
2. Можно создать ветку `dev` для разработки
3. Можно настроить защиту веток
