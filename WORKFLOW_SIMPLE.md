## 🔄 Процесс разработки

### 1. Локально
```
Редактирование кода
    ↓
npm run dev
    ↓
Hot Reload (автоматически)
    ↓
Тестирование в браузере
```

### 2. Деплой
```
npm run build
    ↓
./scripts/deploy-to-server.sh
    ↓
Автоматическая установка на сервер
    ↓
PM2 запускает приложение
    ↓
Nginx проксирует запросы
```

## 📝 Ключевые файлы

| Файл | Назначение |
|------|-----------|
| `lib/data.ts` | Данные моделей и параметров |
| `lib/calculator.ts` | Логика расчета стоимости |
| `components/sofa-calculator.tsx` | UI компонент калькулятора |
| `app/api/sofa-data/route.ts` | API endpoint |
| `app/page.tsx` | Главная страница |

## ⚡ Быстрые команды

```bash
# Разработка
npm run dev              # Запуск dev сервера

# Сборка
npm run build           # Сборка для production

# Деплой
./scripts/deploy-to-server.sh  # Автоматический деплой

# Проверка
curl http://localhost:3000/api/sofa-data  # Проверка API
```

## 🎯 Поток данных

```
Константы (lib/data.ts)
    ↓
API (getSofaData)
    ↓
Компонент (загрузка через fetch)
    ↓
Состояние (useState)
    ↓
Расчет (useMemo + calculateSofaCost)
    ↓
UI (отображение)
```

## 🔧 Изменение данных

1. Открыть `lib/data.ts`
2. Изменить константы
3. Сохранить → Hot reload обновит автоматически
4. Для production: пересобрать и задеплоить
