# 🛠️ Локальная разработка

## Быстрый старт

### Запуск dev сервера

```bash
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:3000**

### Остановка сервера

Нажмите `Ctrl+C` в терминале где запущен сервер.

## 📁 Структура проекта

```
/
├── app/                    # Next.js App Router
│   ├── api/               # API routes
│   │   └── sofa-data/     # API для получения данных
│   ├── layout.tsx         # Главный layout
│   └── page.tsx           # Главная страница
├── components/            # React компоненты
│   ├── sofa-calculator.tsx  # Основной компонент калькулятора
│   └── ui/                # UI компоненты (shadcn/ui)
├── lib/                   # Утилиты и логика
│   ├── data.ts           # Данные моделей и параметров
│   ├── calculator.ts     # Логика расчета стоимости
│   └── utils.ts          # Вспомогательные функции
└── scripts/              # Скрипты для деплоя
```

## 📝 Редактирование данных

Данные моделей и параметров находятся в файле:
- `lib/data.ts`

Для изменения данных откройте этот файл и обновите константы:
- `FIXED_DATA` - фиксированные параметры
- `SOFA_MODELS` - модели диванов

После изменения данных сервер автоматически перезагрузится (hot reload).

## 🎨 Редактирование UI

Основной компонент калькулятора:
- `components/sofa-calculator.tsx`

UI компоненты (shadcn/ui):
- `components/ui/` - все UI компоненты

Стили:
- `app/globals.css` - глобальные стили
- Tailwind CSS конфигурация: `tailwind.config.ts`

## 🔍 Отладка

```bash
curl http://localhost:3000/api/sofa-data
```

### Просмотр логов
Логи отображаются в терминале где запущен `npm run dev`

Откройте DevTools (F12) и проверьте:
- Console - для ошибок JavaScript

## 🚀 Горячая перезагрузка

Next.js автоматически перезагружает страницу при изменении файлов:
- React компоненты
- API routes
- Стили

Просто сохраните файл и изменения применятся автоматически!
